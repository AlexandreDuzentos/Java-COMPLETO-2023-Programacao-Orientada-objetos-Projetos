O curso visa proporcionar uma formação completa em **Java**, cobrindo desde conceitos básicos até tecnologias modernas do ecossistema Java. Além da teoria, o curso possui **projetos práticos** para fixação do conteúdo.  

---

## 📂 Estrutura do Curso  

O curso é dividido em **módulos**, cobrindo diversas tecnologias e conceitos essenciais.  

### **📌 Módulo 1 – Fundamentos de Java**  
✅ Introdução ao Java e configuração do ambiente  
✅ Estruturas de controle e repetição  
✅ Vetores, matrizes e manipulação de dados  

### **📌 Módulo 2 – Programação Orientada a Objetos (POO)**  
✅ Classes, objetos, encapsulamento e herança  
✅ Polimorfismo e interfaces  
✅ Tratamento de exceções  

### **📌 Módulo 3 – Banco de Dados e Persistência**  
✅ **JDBC** – Conexão com bancos de dados relacionais  
✅ **JPA e Hibernate** – Mapeamento objeto-relacional (ORM)  
✅ **MySQL e MongoDB** – Trabalhando com bancos SQL e NoSQL  

### **📌 Módulo 4 – Desenvolvimento de Interfaces Gráficas**  
✅ Introdução ao **JavaFX**  
✅ Criando interfaces com **Scene Builder**  
✅ Eventos e manipulação de elementos gráficos  

### **📌 Módulo 5 – Desenvolvimento Web com Spring Boot**  
✅ Criando **APIs REST** com **Spring Boot**  
✅ **Spring Data JPA** para persistência de dados  
✅ Segurança com **Spring Security e JWT**  

### **📌 Módulo 6 – Projetos Práticos**  
✅ CRUD completo com **JavaFX e JDBC**  
✅ API RESTful com **Spring Boot e JPA**  
✅ Sistema de gerenciamento com **MySQL e MongoDB**  

---

## 🚀 Tecnologias Utilizadas  

- **Java SE 11+**  
- **JPA / Hibernate**  
- **JDBC (Java Database Connectivity)**  
- **MySQL e MongoDB**  
- **JavaFX (Interfaces gráficas)**  
- **Spring Boot**  
- **Spring Data JPA**  
- **UML (Modelagem de Software)**
